# Imaginova V1.5 — PMF 验证：Fashion 优先 + Create 页 SaaS 化

> 创建日期：2026-07-27
> 目标：验证产品-市场匹配（PMF），找到第一个付费场景
> 方向：Fashion / 电商服装为第一验证入口（Game Ads 延后）
> 战略定位：真正的 SaaS 产品，让用户自己使用，而非人工代客生产

---

## 背景

经过多轮分析，核心问题：

> 产品能力已垂直化（Try-On / Style Transfer / Face Transform 各有独立 UI 流程），但入口仍水平化（通用首页 + 通用 Create 页）。

同时确认：

- **用户自己使用**（SaaS）而非外包代客
- **Fashion/Try-On 作为第一验证方向** — 电商服装商家需求明确、付费意愿高
- **Game Ads 延后** — 避免分散精力

---

## 优先级判断

选择 Fashion 而非 Game Ads 的原因：

| 维度 | Fashion (Try-On) | Game Ads |
|------|-----------------|----------|
| 代码完整度 | ✅ Try-On 已有完整表单 | ⚠️ 需要新建模板流程 |
| 用户理解成本 | 低 — "上传衣服换模特" | 中 — 需要理解买量概念 |
| 竞争差异 | 功能已存在，需包装 | 需要建新工作流 |
| 获客渠道 | 电商卖家/Shopify | 游戏发行团队 |

## Day 3-4: Create 页 SaaS 化改造

### 当前问题

Create 页进入后直接展示 Image/Video tabs + Prompt 框 — 用户不知道要做什么。Try-On 等其他模式藏在 Tab 里，需要用户主动发现。

### 改造方案

**变化1：首次访问 / 无 mode 参数时，显示 Studio 选择器**

当 `mode` 参数为空且用户首次访问时，显示 `<StudioSelector>` 组件覆盖在表单上方：

```
┌─────────────────────────────┐
│  What do you want to create?│
│                             │
│  [Fashion Marketing]        │
│   Product photos, model     │
│   try-on, ad creatives      │
│                             │
│  [Free Creation]            │
│   Text-to-image/video,      │
│   style transfer            │
│                             │
│  [Face Studio]              │
│   Gender swap, age          │
│   transformation            │
└─────────────────────────────┘
```

用户选择后跳转到对应的 mode，后续访问直接进入上次选择（localStorage 记忆）。

**变化2：Fashion 模式下简化 UI**

当 `mode=try-on` 时，顶部模式切换栏仍然显示，但隐藏 Image/Video tabs（Try-On 不需要），直接渲染 `TryOnForm`。

**新增文件：`src/components/studio-selector.tsx`**

3 个卡片的选择界面，点击后 `router.push('/create?mode=...')` 或跳转到 Landing Page。

### 不改的部分

- 不修改 `TryOnForm` / `StyleTransferForm` / `GenderSwapForm` / `AgeTransformForm` 内部逻辑
- 不修改 Dashboard
- 不修改积分系统

## Day 5-6: Fashion Landing Page

### 新建 `src/app/fashion/page.tsx`

独立页面，使用 `Navbar variant="home"`，不继承 dashboard/detail 布局。

**页面结构：**

1. **Hero** — 全屏高度
   - 标题: `t("fashion.heroTitle")` — "AI Fashion Marketing Studio"
   - 副标题: `t("fashion.heroSub")`
   - 按钮: "Try It Now" → `/create?mode=try-on`，"See Examples" → 锚点

2. **Use Cases** — 3 列卡片
   - Product Photography — 商品图 → 模特上身
   - Ad Creatives — 社媒广告素材
   - Video Ads — 15 秒推广视频

3. **How It Works** — 4 步骤横向流程
   - Upload → Choose Style → AI Generates → Download

4. **Showcase** — Before/After 案例网格
   - 使用 `fashion-showcase.tsx` 组件
   - 占位图片，上线后替换为用户生成结果

5. **Pricing** — 3 级定价卡片
   - Starter / Pro / Business
   - CTA 指向 `/credits`

6. **CTA Footer** — "Start creating fashion visuals" → `/create?mode=try-on`

**新增文件：`src/components/fashion-showcase.tsx`**

展示 Before/After 对比网格。Props 接收图片数组，默认用占位图。
